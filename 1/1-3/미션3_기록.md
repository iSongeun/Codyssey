# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| 같은 브라우저에서 다시 열었을 때 기존 영화 목록과 등급이 유지되어야 한다. | 새로운 파일을 열었을 때 기존 데이터가 표시되지 않는 것을 확인했다. 다만 기획서의 조건은 '같은 브라우저에서 같은 파일을 다시 열었을 때'이므로, 다른 파일을 연 테스트만으로는 기획서 위반인지 확정할 수 없다. | 되묻기 | 여기서 말한 '새로운 파일'이 기존에 사용하던 것과 동일한 HTML 파일을 다시 연 것인지 확인이 필요하다. 동일한 파일을 다시 열어도 데이터가 사라지는지 다시 테스트해야 한다. |
| 화면 폭을 좁혀도 오른쪽이 잘리지 않고 내용을 볼 수 있어야 한다. | 화면 폭을 줄였더니 화면 일부가 잘리는 것을 확인했다. | 반영 | 기획서의 완성 기준에 좁은 화면에서도 오른쪽이 잘리지 않아야 한다고 명시되어 있으므로 수정하는 것이 좋다. |
| 제목을 비워 두고 추가했을 때 가짜 데이터가 생기지 않아야 한다. | 빈 제목을 입력했을 때 가짜 데이터가 추가되는 현상을 확인했다. | 반영 | 기획서의 완성 기준에 제목이 비어 있거나 공백뿐이면 카드를 만들지 않고 입력 안내를 보여 주어야 한다고 명시되어 있다. |
| '처음으로'를 눌러도 임의로 추가한 데이터는 남겨야 한다. | '처음으로' 버튼을 누르면 임의로 추가한 데이터도 남겨 달라는 의견이다. | 보류 | 기획서에는 '처음으로'를 누르면 처음 영화 8개가 모두 미분류로 돌아간다고 명시되어 있다. 추가한 영화까지 남기는 동작은 기획서의 초기화 목적과 다르므로 반영하지 않는 것이 맞다. |

- 아무도 말하지 않았는데 내가 찾은 것: 현재 제공된 정보만으로는 별도로 확인한 항목이 없어 작성하지 않았다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 같은 브라우저에서 같은 HTML 파일을 다시 열었을 때의 저장 동작을 어떤 조건으로 테스트해야 하는지 이야기하고 싶다. 다른 파일을 여는 것과 같은 파일을 다시 여는 것은 결과가 다를 수 있기 때문이다.
