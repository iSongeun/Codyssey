## 수정 기록

> 한 번에 하나씩 수정하고, 수정한 HTML 전체를 버전별로 저장했습니다. 매 수정 뒤에는 고친 부분과 함께 기존 기능(총 구매 금액 ₩481,000, Rock 필터 1장, 가격순 첫 LP ₩62,000, 그리드 뷰 10장, 빈칸 등록 안내, LP 등록·새로고침 유지, 삭제, 넓은 화면·390px 화면 가로 스크롤 없음)을 다시 테스트했습니다.

### 수정 기록 1
- 발견한 문제:
  - 테스트 내용: 좁은 화면(390px)에서 3D 랙 뷰의 5번째·10번째 LP에 마우스를 올린다. 같은 넓은 화면(1280px)에 LP 25장을 넣고 랙 뷰를 본다.
  - 예상 결과: 올린 LP와 정보 글자가 상자 안에 다 보이고, LP가 많아도 한눈에 볼 수 있다.
  - 실제 결과: 390px에서 5번째·10번째 LP가 상자 오른쪽 끝에서 잘렸고 정보 글자도 "summer f…"까지만 보였다(이전 미션 테스트 3-③). 25장을 넣으면 상자 하나에 25장이 한 줄로 꽂혀서 상자 안을 가로로 밀어야 뒤쪽 LP를 볼 수 있었다.
- AI에게 전달한 요청: "좁은 화면(390px)에서 랙 뷰 오른쪽 LP에 마우스를 올리면 상자 밖으로 잘려서 앨범 정보가 'summer f…'까지만 보여. 그리고 LP가 많아지면 한 줄 랙을 가로로 계속 밀어야 해서 보기 힘들어. LP가 10장 단위로 밑으로 내려가게 하고, 어떤 화면에서도 올린 LP가 잘리지 않게 해 줘. 다른 기능은 그대로 두고 고친 HTML 전체를 줘."
- 저장한 버전: `LP컬렉션_v1.html` → `LP컬렉션_v2.html`
- 수정 후 테스트 결과: LP 25장을 넣으니 상자 3개(10장 / 10장 / 5장)가 아래로 쌓였고 상자마다 "MY RECORD CRATE 01 · 1–10"처럼 번호가 붙었습니다. 상자 안 가로 스크롤이 없어졌습니다. 390px 화면에서 1·5·10번째 LP를 올려 보니 LP와 정보 글자가 모두 상자 안에 보였습니다(오른쪽 LP는 정보 글자가 오른쪽 정렬로 표시됨). 기존 기능도 모두 그대로 동작했습니다. 다만 390px에서는 한 줄에 10장이 들어가 LP가 작게 보이고, 마우스를 올렸을 때 크게 보입니다.
- 수정 이유: 휴대폰으로 컬렉션을 보는 사용자는 오른쪽 LP의 이름을 읽을 수 없고, LP가 많은 수집가는 상자를 계속 옆으로 밀어야 해서 "한눈에 보기"라는 사용 목적을 이룰 수 없습니다.

### 수정 기록 2
- 발견한 문제:
  - 테스트 내용: "+ LP 등록"을 눌러 갖고 있는 LP의 표지 사진을 넣어 등록해 본다.
  - 예상 결과: 표지 이미지를 첨부해 실제 앨범 표지로 등록할 수 있다.
  - 실제 결과: 등록 창에 표지 색상 10가지 중 하나를 고르는 칸만 있고 이미지를 넣는 칸이 없어서, 등록한 LP가 모두 색상과 글자로 된 표지로만 표시됐다.
- AI에게 전달한 요청: "LP를 등록할 때 표지 색상만 고를 수 있고 이미지를 넣을 방법이 없어. 등록 창에서 이미지 파일 첨부로도 표지 이미지를 올릴 수 있게 해 줘. 이미지가 없으면 지금처럼 색상 표지가 나오게 하고, 다른 기능은 그대로 두고 고친 HTML 전체를 줘."
- 저장한 버전: `LP컬렉션_v2.html` → `LP컬렉션_v3.html`
- 수정 후 테스트 결과: 등록 창에 "표지 이미지(선택)" 칸이 생겼습니다. "이미지 파일 첨부"로 800×600 이미지를 고르니 미리보기에 정사각형으로 잘린 표지가 바로 보였고, 등록하니 랙에 그 이미지가 표지로 꽂혔습니다. 새로고침 후에도 이미지 표지가 남아 있었습니다. 이미지를 끌어다 놓거나 https:// 이미지 주소를 붙여 넣는 방법도 생겼고, 이미지 없이 등록하면 예전처럼 색상 표지가 만들어졌습니다. 수정 기록 1의 10장 단위 상자와 기존 기능도 그대로 동작했습니다.
- 수정 이유: 수집가는 자기 LP를 표지로 알아보는데, 모든 LP가 색상 표지로만 나오면 비슷한 색의 앨범을 구분하기 어렵고 진열장을 보는 재미도 줄어듭니다.

### 수정 기록 3
- 발견한 문제:
  - 테스트 내용: 3집 TEAM BABY의 상세 팝업을 열어 구매 금액을 55,000원에서 60,000원으로 고쳐 본다.
  - 예상 결과: 상세 팝업에서 정보를 고치고 저장할 수 있다.
  - 실제 결과: 상세 팝업에 "삭제"와 "닫기" 버튼만 있어서, 값을 고치려면 삭제한 뒤 처음부터 다시 등록해야 했다.
- AI에게 전달한 요청: "등록한 LP의 가격이나 앨범명을 잘못 넣었을 때 고칠 방법이 없어. 상세 팝업에 '삭제'와 '닫기'만 있어서 지우고 다시 등록해야 해. 상세 팝업에 수정 기능을 추가해서 기존 값이 채워진 창에서 고칠 수 있게 해 줘. 다른 기능은 그대로 두고 고친 HTML 전체를 줘."
- 저장한 버전: `LP컬렉션_v3.html` → `LP컬렉션_v4.html`
- 수정 후 테스트 결과: 상세 팝업에 "수정" 버튼이 생겼습니다. 3집 TEAM BABY에서 누르니 기존 값(TEAM BABY / 3집 / 55000)이 채워진 창이 열렸습니다. 앨범명을 지우고 저장하니 "앨범명을 입력해 주세요." 안내가 뜨고 저장되지 않았습니다. 앨범명을 "TEAM BABY (Repress)", 가격을 60000으로 바꿔 저장하니 상세 팝업에 바로 반영됐고 총 구매 금액이 ₩481,000에서 ₩486,000으로 바뀌었습니다. 새로고침 후에도 바뀐 값이 유지됐습니다. 이미지 첨부, 10장 단위 상자, 삭제 등 기존 기능도 그대로 동작했습니다.
- 수정 이유: 구매 금액은 총 구매 금액 통계에 바로 쓰이는데, 잘못 넣은 값을 고치려고 매번 지우고 다시 등록해야 하면 번거롭고, 그대로 두면 통계를 믿을 수 없게 됩니다.
