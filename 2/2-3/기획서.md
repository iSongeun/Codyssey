# LP 컬렉션 한눈에 보기 진열장

## 대상 사용자

- LP(바이닐) 레코드를 수집하며 자신의 컬렉션을 군더더기 없이 한눈에 정리하고 관리하고 싶은 LP 수집가

## 사용 목적

- 소장 중인 LP를 구매 금액, 연도, 장르별로 편리하게 분류 및 필터링하여 감상하고, 무채색 미니멀 UI를 통해 자신의 컬렉션을 효율적으로 시각화하기 위함

## 화면 구성과 동작

- **뷰 모드 전환 버튼 (3D LP 랙 뷰 ↔ 그리드 뷰)**:
  - 기본 제공되는 '3D 입체 겹침 랙 뷰(Record Crate View)'와 깔끔한 '그리드 뷰(Grid View)'를 자유롭게 선택할 수 있는 스위처 제공
  - 마지막으로 고른 보기 방식을 기억해 다시 열었을 때 그대로 표시
- **미니멀 헤더 & 요약 바**:
  - 여백을 충분히 활용한 깔끔한 타이틀
  - 총 소장 LP 수, 총 구매 금액 합계, 아티스트 수를 간결한 텍스트 칩 형태로 배치 (필터·검색 중에는 '표시 중 n장' 칩 추가)
- **상단 필터 및 정렬 컨트롤**:
  - 심플한 드롭다운 (장르 선택: 전체, Indie, K-Indie, K-Pop, Pop, Ballad, R&B, Rock, Folk 등, 장르별 개수 표시). 'Indie'를 고르면 K-Indie, Indie Pop, Indie Rock 등 Indie가 들어간 장르를 함께 표시
  - 깔끔한 텍스트 방식의 정렬 옵션 (등록순, 가격순, 연도순 / 같은 버튼을 다시 누르면 오름차순·내림차순 전환)
  - 간결한 검색창 (앨범명 또는 아티스트명 입력)
- **메인 LP 진열판**:
  - **3D LP 랙 뷰 (기본)**: LP 상자 안에서 판들이 입체적으로 사선 겹침 배치되며, 마우스 호버 시 해당 LP가 위로 올라오며 정면을 보고, 슬리브에서 바이닐이 빠져나오면서 표지와 상세 정보(앨범명·아티스트·연도·가격)가 또렷하게 나타나는 연출
  - **10장 단위 상자**: LP는 상자 하나에 10장씩 꽂히고, 10장을 넘으면 새 상자가 아래로 쌓임 (상자마다 'MY RECORD CRATE 01 · 1–10'처럼 번호 표시). LP 크기는 상자 폭에 맞춰 자동으로 조절되어 넓은 화면과 휴대폰 화면 모두 가로 스크롤 없이 표시
  - **이전/다음 LP 이동**: 랙 아래 정보 줄의 '‹ 이전 · 다음 ›' 버튼이나 키보드 ← → 키로 꺼낸 LP를 한 장씩 옮겨 볼 수 있음. 현재 위치를 '5 / 10'처럼 표시하고, 10장을 넘으면 다음 상자로 이어지며, 마지막 LP에서 다음을 누르면 처음으로 돌아감. 꺼낸 LP는 Enter로 상세 정보를 열 수 있음
  - **모던 그리드 뷰**: 얇은 테두리와 여백 중심의 미니멀 카드 레이아웃
  - LP를 클릭하면 상세 정보(발매 연도, 장르, 구매 금액, 컬렉션 비중)를 보여주는 미니멀 모달 팝업 표시
- **LP 등록·수정·삭제 (브라우저 LocalStorage 저장)**:
  - '+ LP 등록' 버튼으로 아티스트, 앨범명, 음반 차수(선택), 장르, 발매 연도, 구매 금액, 표지 이미지(선택), 표지 색상을 입력해 등록
  - 표지 이미지는 이미지 파일 첨부(클릭 또는 끌어다 놓기)나 https:// 이미지 주소로 넣을 수 있고, 이미지가 없으면 고른 색상으로 표지를 자동 생성
  - 상세 팝업의 '수정' 버튼으로 기존 값이 채워진 창에서 정보를 고치고, '삭제' 버튼은 두 번 눌러야 삭제
  - 필수 항목이 비어 있으면 어떤 칸이 비었는지 안내 문구를 보여 주고 저장하지 않음
- **디자인**: 연한 회색 배경, 회색 상자, 검정 버튼의 무채색 미니멀 스타일. LP 표지만 색을 가져 컬렉션이 돋보이도록 함

## 완료 기준

- 뷰 전환 스위처 클릭 시 3D LP 랙 뷰와 그리드 뷰 간 전환이 화면 깨짐 없이 원활하게 이루어져야 합니다.
- 장르 드롭다운 선택 시 해당 장르의 LP만 정상적으로 필터링되어 출력되어야 합니다.
- 정렬 옵션(가격순, 연도순) 변경 시 LP 카드의 순서가 즉시 재배치되어야 합니다.
- 가로 스크롤이 이중으로 생기지 않고 단 하나의 스크롤바만 동작해야 합니다. 좁은 화면(390px)에서도 마우스를 올린 LP와 정보 글자가 상자 밖으로 잘리지 않아야 합니다.
- LP가 10장을 넘으면 새 상자가 아래로 추가되어야 합니다. (예: 25장 → 10장 / 10장 / 5장)
- 랙 뷰에서 '다음 ›'·'‹ 이전' 버튼이나 ← → 키를 누르면 꺼낸 LP가 한 장씩 바뀌고 정보 줄과 위치(예: 5 / 10)가 함께 바뀌어야 합니다.
- LP 등록 시 이미지 파일을 첨부하면 그 이미지가 표지로 표시되고, 새로고침 후에도 유지되어야 합니다.
- 상세 팝업에서 '수정'으로 바꾼 값이 즉시 반영되고 새로고침 후에도 유지되어야 합니다. 필수 항목을 비우면 저장되지 않아야 합니다.
- 별도의 백엔드 서버나 외부 라이브러리 설치 없이 HTML 파일 하나만 브라우저로 열었을 때 모든 동작(필터링, 정렬, 통계 계산, 뷰 전환, 등록·수정·삭제)이 정상 작동해야 합니다.

## 추가 기능

- (구현 완료 → 본문으로 이동) LP 등록·삭제, 호버 애니메이션은 '화면 구성과 동작'에 포함했습니다.
- 현재 버전에서 구현하지 않은 추가 기능
  - 컬렉션 데이터를 파일로 내보내고 다른 기기에서 불러오는 백업 기능
  - 여러 기기에서 컬렉션을 동기화하는 기능 (서버·로그인이 필요하므로 이번 범위에서 제외)

## 한계 및 비목표

1. 실제 외부 음악 스트리밍 서비스(Spotify, Apple Music 등)와의 API 연동 및 실시간 음원 재생 기능은 구현 범위에서 제외합니다.
2. 실시간 음반 시세 조회나 중고 거래 플랫폼과의 연동 기능은 포함하지 않습니다.
3. 사용자 회원가입, 로그인 및 서버 기반의 데이터베이스 저장 기능은 구현하지 않으며 단일 페이지 프론트엔드 동작에 집중합니다. (데이터는 사용하는 브라우저의 LocalStorage에만 저장되며, 첨부한 이미지는 저장 공간을 아끼기 위해 480px 정사각형으로 줄여 저장합니다.)

## 검증 방법

- 샘플 데이터 10개를 넣었을 때, 상단 요약 섹션에 표시되는 '총 구매 금액' 수치(₩481,000)가 샘플 데이터 10개의 구매 가격을 직접 손으로 더한 합계 금액과 정확히 일치하는지 대조 확인합니다.
