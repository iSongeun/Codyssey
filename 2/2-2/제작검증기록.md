## 수정 기록

> 아래 세 가지는 한 번의 요청으로 함께 전달해 `LP컬렉션_v1.html` → `LP컬렉션_v2.html`로 저장했습니다.
> 실제 전달한 요청: "수정할거 말해줄게 3가지, 1. 이미지 등록시 이미지 첨부로도 이미지 업로드를 가능하게 한다. 2. lp갯수가 많아지면 랙으로 보기 힘들어지니까 10장 단위로 밑으로 내려간다 3. 수정 기능을 추가한다"

### 수정 기록 1
* 발견한 문제: LP를 새로 등록하면 표지가 색상과 글자로만 만들어졌습니다. 실제 앨범 표지를 넣을 수 있을 줄 알았는데 이미지를 넣는 방법이 없었습니다.
* AI에게 전달한 요청: "1. 이미지 등록시 이미지 첨부로도 이미지 업로드를 가능하게 한다."
* 저장한 버전: `LP컬렉션_v1.html` → `LP컬렉션_v2.html`
* 수정 후 테스트 결과: 등록 창에 "표지 이미지(선택)" 칸이 생겼습니다. "이미지 파일 첨부"로 800×600 이미지를 고르니 미리보기에 정사각형으로 잘린 표지가 바로 보였습니다. 등록하니 랙에 그 이미지가 표지로 꽂혔고, 새로고침 후에도 표지가 남아 있었습니다. 이미지를 끌어다 놓거나 https:// 이미지 주소를 붙여 넣어도 넣을 수 있고, 이미지가 없으면 예전처럼 색상 표지가 만들어집니다.
* 수정 이유: 수집가는 자기 LP를 실제 표지로 알아보는데, 색상 표지만으로는 어떤 앨범인지 한눈에 찾기 어렵습니다.

### 수정 기록 2
* 발견한 문제: 랙 뷰는 LP 전부를 한 상자에 가로로 꽂아서, LP가 많아질수록 상자 안에서 가로로 계속 밀어야 했습니다. 좁은 화면(390px)에서는 오른쪽 끝 LP를 올렸을 때 상자 밖으로 잘렸습니다(테스트 3-③).
* AI에게 전달한 요청: "2. lp갯수가 많아지면 랙으로 보기 힘들어지니까 10장 단위로 밑으로 내려간다"
* 저장한 버전: `LP컬렉션_v1.html` → `LP컬렉션_v2.html`
* 수정 후 테스트 결과: LP를 25장으로 늘리니 상자가 3개(10장 / 10장 / 5장)로 나뉘어 아래로 쌓였고, 상자마다 "MY RECORD CRATE 01 · 1–10"처럼 번호가 붙었습니다. LP 크기가 상자 폭에 맞춰져서 넓은 화면과 390px 화면 모두 가로 스크롤이 생기지 않았습니다. 390px 화면에서 1·5·10번째 LP를 올렸을 때 LP와 정보 글자 모두 상자 안에 다 보였습니다(오른쪽 LP는 정보 글자가 오른쪽 정렬로 표시됨).
* 수정 이유: 기획서의 사용 목적이 "컬렉션을 한눈에" 보는 것인데, LP가 많아질수록 한 줄 랙으로는 가로로 밀어야 해서 전체를 한눈에 볼 수 없습니다.

### 수정 기록 3
* 발견한 문제: 등록한 LP의 가격이나 앨범명을 잘못 입력했을 때 고칠 방법이 없어서, 삭제하고 처음부터 다시 등록해야 했습니다.
* AI에게 전달한 요청: "3. 수정 기능을 추가한다"
* 저장한 버전: `LP컬렉션_v1.html` → `LP컬렉션_v2.html`
* 수정 후 테스트 결과: LP 상세 창에 "수정" 버튼이 생겼습니다. 3집 TEAM BABY에서 누르니 기존 값(TEAM BABY / 3집 / 55000)이 채워진 수정 창이 열렸습니다. 앨범명을 지우고 저장하니 "앨범명을 입력해 주세요." 안내가 뜨고 저장되지 않았습니다. 앨범명을 "TEAM BABY (Repress)", 가격을 60000으로 바꿔 저장하니 상세 창에 바로 반영됐고, 새로고침 후에도 바뀐 값이 유지됐습니다.
* 수정 이유: 구매 금액은 총 구매 금액 통계에 바로 쓰이므로, 잘못 입력한 값을 쉽게 고칠 수 있어야 통계를 믿을 수 있습니다.
