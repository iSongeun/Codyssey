## 3. 비교 기준

1. 개인화 수준: 사용자의 경력과 기술 역량을 얼마나 정확하게 반영하는가?
2. 실행 가능성: 제시한 로드맵과 TODO를 실제로 수행할 수 있는 수준으로 구체적으로 제공하는가?
3. 공고 적합성: 목표 직무와 실제 채용공고의 요구사항을 얼마나 잘 반영하는가?
4. 가독성: 결과의 구성과 표, 문장이 이해하기 쉽고 한눈에 확인하기 편한가?
5. 요구사항 반영도: 사용자가 요청한 조건과 목표를 충분히 반영하는가?

## 5. 최종 선정 모델 및 선정 이유

**최종 선정 모델: ChatGPT (GPT-6)**

ChatGPT를 최종 모델로 선정했습니다.

선정 이유는 다음과 같습니다.

- 가독성이 가장 좋았습니다. 글과 표의 구성이 자연스럽고, 전체 로드맵을 한 화면에서 확인하기 편했습니다.
- 개인화 수준이 가장 높았습니다. 이전 대화에서 제공한 경력과 기술 역량을 잘 파악하고 이를 로드맵에 반영했습니다.
- 실행 가능한 TODO를 구체적으로 제시했으며, 실제 채용공고에서 공통적으로 요구하는 기술도 파악했습니다.
- 전반적으로 사용자의 목표와 요구사항을 가장 충실하게 반영했다고 판단했습니다.

따라서 이후 취업 준비 비서의 System Prompt 테스트와 개선 작업에는 ChatGPT를 선정 모델로 사용했습니다.

## 6. 평가 시 참고사항

- 각 모델에 동일한 과업 프롬프트를 입력해 결과를 비교했습니다.
- 점수와 평가 근거는 실제 응답을 확인한 후 작성했습니다.
- 모델별 세부 버전이 확인되지 않은 경우 임의로 추정하지 않았습니다.
- 비교 조건의 한계: ChatGPT는 이전 대화 기록이 많이 쌓여 있어, 과업 프롬프트에 없는 경력 정보까지 반영했습니다. 따라서 '개인화 수준' 점수에는 모델 성능뿐 아니라 계정에 쌓인 대화 기록의 영향이 포함되어 있습니다.
- '공고 적합성'은 과업 프롬프트에서 채용공고 검색을 직접 요구하지 않았지만, 목표 직무의 실제 요구사항을 반영하는지가 로드맵 품질에 중요하다고 판단해 기준에 넣었습니다.
