# 미션 2 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: ChatGPT / 대화 캡처 이미지
- 좁혀서 적은 한 문장: 영화 제목에 띄어쓰기가 포함된 카드를 드래그 앤 드롭하면 일부 영화가 티어로 이동하지 않는 문제
- 좁히려고 해 본 것과 결과: 영화 8개를 직접 드래그 앤 드롭하여 테스트, 3개 영화가 이동하지 않는 것을 확인, 이동되는 영화와 이동되지 않는 영화의 차이를 비교한 결과 제목에 띄어쓰기가 있는 경우 문제가 발생한다는 것을 확인.
- AI가 말한 원인과, 그 설명을 직접 확인한 결과: AI는 영화 카드 생성 코드에서 `data-id` 속성에 영화 ID를 따옴표 없이 삽입한 것이 원인이라고 설명했다. HTML에서 공백을 기준으로 속성이 분리되어 영화 ID가 잘못 저장되고, 이로 인해 드래그 앤 드롭 시 원래 영화를 찾지 못하는 문제라고 했다. 개발자 도구에서 영화 카드의 `dataset.id` 값을 확인하는 방법도 안내받았다.

| 파일명 | 고친 내용 | 다시 해 본 결과 |
|---|---|---|
| 영화_수정전.html | 영화 카드 생성 시 HTML 문자열에 ID와 제목을 직접 삽입하던 코드를 DOM 요소를 직접 생성하는 방식으로 변경했다. `dataset.id`에 영화 ID를 저장하고 `textContent`로 제목을 표시하도록 수정했다. | 수정된 HTML에서 띄어쓰기가 포함된 영화 3개를 다시 드래그 앤 드롭하여 정상 이동하는지 확인 필요 |
